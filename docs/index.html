How the data moves

Each page keeps its data as one JSON file in My Drive → Personal Apps. The browser caches a copy so pages open instantly and work offline; changes are saved to Drive a second or two after you make them and picked up by your other devices within about a minute, or the moment you return to the page.

The vault file holds only ciphertext. Your master password never leaves the device.

On a phone

  1. Open this page in Chrome or Safari and sign in with Google.
  2. Use the browser's Add to Home Screen for the pages you use most.
