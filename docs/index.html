      Install it on a phone

      1. Open this page in Chrome and tap Continue with Google once.
      2. Chrome menu (⋮) → Install app, or Add to Home screen if that is what it offers. On an iPhone or iPad: Share → Add to Home Screen.
      3. It then opens full-screen from its own icon, like an app.

      How the data moves

      Each app keeps its data as one JSON file in My Drive → Personal Apps; the to-do list above is home.json. The browser keeps a copy so pages open instantly and work offline. Changes are saved to Drive a second or two after you make them, and your other devices pick them up within about a minute, or the moment you come back to the page.

      Until you sign in on a device, its to-dos stay in that browser only. On a work laptop you can use every link without signing in.

      The vault file holds only ciphertext. Your master password never leaves the device.
